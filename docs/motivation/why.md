# Why Neo language

I created Neo as an educational project with a goal to explore language design and learn how does it really work under the hood. It was for me a place to try out ideas, mix features from languages that I like, and learn what works - and what doesn’t - on my own.

I have always payed close attention to the quirks of the languages that I have used and was thinking what was the decision behind them. There is so much quirks, twists and sometimes questionable decisions. For example:
- Why the new keyword in the Javascript seems optional, since new Array() works the same as Array()?
- Why do we need semicolons in Java, if JavaScript can live without it (unless you start new line with destructuring array and suddenly everything breaks)?

While designing my language I also needed to make a lot of decision all the time and after some time I understood that you cannot design a perfect language. There is always a trade off to make. Now I can forgive the creators of my favourite languages and live and code with peace.

Ultimately Neo is about learning and having fun with language design. It’s imperfect by intention - changes are constant and straightforward, the roadmap is driven by experimentation, and feedback is welcome.
